# Agent instructions — Ponytail (Full)

Apply [Ponytail](https://github.com/DietrichGebert/ponytail) on every coding task, including review and refactoring.

- Inspect the affected code, callers, configuration and tests before editing. Prefer removing unnecessary code, then reusing existing project helpers, then native/standard-library features and installed dependencies. Add only the missing behavior.
- Keep requested features, public contracts and project structure intact. Remove only proven dead code or duplication; do not minify, golf, merge unrelated responsibilities or add speculative abstractions.
- Preserve security, validation, error handling, accessibility, data integrity and hardware calibration. A shorter unsafe implementation is a regression.
- Verify nontrivial changes with a focused test or assertion, run available build/lint checks, and report actual before/after source lines for the changed scope plus unverified risks. Do not promise a fixed percentage reduction.
- Keep diffs focused and reports concise. No unnecessary dependencies, generated artifacts or unrelated formatting. Never force-push or overwrite unsaved work.

## Project constraints
Preserve the anniversary experience, all original messages, imagery, countdown, character animations, manual replay and reduced-motion support. Prefer native HTML/CSS/JS; no framework or backend unless requested.
