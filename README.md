# November 24 — A little universe for us

A romantic, responsive anniversary microsite. Built as a single static HTML file with CSS and JavaScript animations; no framework, build step, backend, or API keys required.

## Preview locally
Open `index.html` in any modern browser.

## Deploy
The included GitHub Actions workflow publishes the static site to GitHub Pages when the branch is updated. In the repository settings, enable Pages with **GitHub Actions** as the source if needed.

## Personalise it
Edit the letter, memory cards, page title, and text in `index.html` before sharing. The countdown automatically targets the next November 24.

Motion respects the visitor's reduced-motion accessibility preference.
